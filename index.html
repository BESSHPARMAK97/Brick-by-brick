Справка

Грунтдо 1,5 м1,5–3 м3–5 мKр
  • Любой контур с откосами: V = F·H + P·m·H²/2 + K·m²·H³/3. F и P — площадь и периметр дна, K = Σ tg(φ/2) по углам поворота контура.
  • У контура только с прямыми углами (Г, П, Т, ступенчатый) K = 4: выпуклый угол даёт +1, входящий −1. Для прямоугольника формула совпадает с формулой обелиска.
  • С креплением (шпунт, сваи, «стена в грунте»): V = F·H, площадь по формуле Гаусса.
  • Пандус: V = H²/6·[3b + 2mH·(m′−m)/m′]·(m′−m).
  • Глубже 5 м откосы назначают по расчёту устойчивости. Для Алматы и других сейсмичных районов в расчёт входит сейсмическая нагрузка.
  • Вывоз считается за вычетом грунта, оставленного на засыпку пазух: V_засыпки / Kор в плотном теле.
Калькулятор даёт предварительный объём на ровной площадке с одной отметкой дна. Приямки, ступенчатое дно и неровный рельеф считаются отдельно. Для рабочей документации и смет сверяйте нормативы с действующими редакциями СП РК / СН РК.

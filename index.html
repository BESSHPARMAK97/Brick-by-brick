Справка: крутизна откосов без крепления

Грунтдо 1,5 м1,5–3 м3–5 мKр
  • Котлован с откосами: V = H/6·[(2a+a₁)·b + (2a₁+a)·b₁], где a₁ = a + 2mH, b₁ = b + 2mH.
  • С креплением (шпунт, сваи, «стена в грунте»): V = a·b·H.
  • Пандус: V = H²/6·[3b + 2mH·(m′−m)/m′]·(m′−m).
  • Глубже 5 м откосы назначают по расчёту устойчивости. Для Алматы и других сейсмичных районов в расчёт входит сейсмическая нагрузка.
  • Вывоз считается за вычетом грунта, оставленного на засыпку пазух: V_засыпки / Kор в плотном теле.
Калькулятор даёт предварительный объём для прямоугольного котлована на ровной площадке. Для рабочей документации и смет сверяйте нормативы с действующими редакциями СП РК / СН РК, а рельеф учитывайте методом квадратов по топосъёмке.

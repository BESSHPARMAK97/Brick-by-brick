# Жобалық қаржыландыруға құжаттар пакеті

> Танысуға арналған үлгі. Пайдаланар алдында құжатты заңгермен бірге ҚР қолданыстағы заңнамасына бейімдеңіз.

```text
ЖОБАНЫ ҚАРЖЫЛАНДЫРУ ҮШІН БАНККЕ / ҚТҮК-ҚА ҚҰЖАТТАР ПАКЕТІ
(нақты тізбені кредитордан сұраңыз — әр банктің өз талаптары бар)

ҚАРЫЗ АЛУШЫ ТУРАЛЫ
[ ] Құрылыс салушы ЖШС-ның құрылтай құжаттары, тіркеу туралы анықтама
[ ] Қатысушылардың қаржыландыру тарту және кепіл туралы шешімі
[ ] [___] жылғы қаржылық есептілік (жаңа SPV үшін — бас компанияның есептілігі)
[ ] Салық берешегінің жоқтығы туралы анықтама
[ ] Тәжірибе: пайдалануға беру актілері бар іске асырылған объектілер тізбесі

ЖОБА ТУРАЛЫ
[ ] Инвестициялық меморандум / бизнес-жоспар
[ ] Ақша ағындарының кестесі бар қаржы моделі (ай сайын)
[ ] Жерге құжаттар, ауыртпалықтың жоқтығы
[ ] СЖТ, ТШ, эскиздік жоба, ЖСҚ және сараптама қорытындысы (немесе оларды алу кестесі)
[ ] Смета және бас мердігерлік шарт (немесе шарт жобасы)
[ ] Құрылыс кестесі және сату кестесі
[ ] Нарықты маркетингтік зерттеу

ҚАМТАМАСЫЗ ЕТУ
[ ] Жер учаскесі мен аяқталмаған құрылыс объектісінің кепілі
[ ] Үлестік қатысу шарттары бойынша талап ету құқықтарының / болашақ түсімдердің кепілі
[ ] Құрылтайшылардың кепілдіктері / кепілгерлігі
[ ] Тәуелсіз бағалаушының есебі

МЕНШІКТІ ҚАТЫСУ

```

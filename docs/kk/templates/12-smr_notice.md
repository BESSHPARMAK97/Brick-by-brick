# ҚМЖ басталғаны туралы хабарлама: мәліметтер тізбесі

> Танысуға арналған үлгі. Пайдаланар алдында құжатты заңгермен бірге ҚР қолданыстағы заңнамасына бейімдеңіз.

```text
ҚҰРЫЛЫС-МОНТАЖ ЖҰМЫСТАРЫНЫҢ БАСТАЛҒАНЫ ТУРАЛЫ ХАБАРЛАМА — НЕНІ ДАЙЫНДАУ КЕРЕК
(мемлекеттік сәулет-құрылыс бақылауы органдарына портал арқылы электрондық түрде беріледі; нысанын қолданыстағы қағидалар айқындайды)

ТАПСЫРЫС БЕРУШІ ТУРАЛЫ МӘЛІМЕТТЕР
[ ] Атауы, БСН, мекенжайы, басшысы, ЭЦҚ

ОБЪЕКТ ТУРАЛЫ МӘЛІМЕТТЕР
[ ] Объектінің атауы мен мекенжайы, учаскенің кадастрлық нөмірі
[ ] Жауапкершілік деңгейі, техникалық сипаттамалары (қабаттылығы, ауданы)
[ ] Құрылыстың басталуы мен аяқталуының жоспарлы күндері

ҚҰЖАТТАР
[ ] ЖСҚ-ның ведомстводан тыс кешенді сараптамасының оң қорытындысы
[ ] Жер учаскесіне сәйкестендіру құжаты
[ ] Бас мердігерлік шарт, бас мердігердің лицензиясы
[ ] Техникалық қадағалау шарты, техникалық қадағалау сарапшыларының аттестаттары
[ ] Авторлық қадағалау шарты
[ ] Жауапты тұлғаларды тағайындау туралы бұйрықтар (тапсырыс беруші, бас мердігер)

БЕРГЕННЕН КЕЙІН
[ ] Хабарламаның қабылданғаны туралы растама алынды
[ ] Объект паспорты қоршауға орнатылды
[ ] Жұмыстардың жалпы журналы ашылды
```

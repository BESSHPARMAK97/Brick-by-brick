# Жобалау шарты: негізгі талаптар

> Танысуға арналған үлгі. Пайдаланар алдында құжатты заңгермен бірге ҚР қолданыстағы заңнамасына бейімдеңіз.

```text
ЖОБАЛАУ ЖҰМЫСТАРЫН ОРЫНДАУ ШАРТЫ — НЕГІЗГІ ТАЛАПТАР (term sheet)

Тараптар: Тапсырыс беруші [Құрылыс салушы]; Жобалаушы [___], лицензия № [___], санаты [___]
Мәні: «[ТҮК атауы]» объектісі бойынша Жобалауға тапсырмаға (1-қосымша) сәйкес [П / ЖЖ / ЖҚ] сатыларының ЖСҚ-сын әзірлеу

Бағасы: [___] тг, оның ішінде ҚҚС [___] / ҚҚС-сыз. Тіркелген, тек Тапсырма өзгерген кезде өзгереді.
Кезеңдер және төлем:
  1. Эскиздік жоба — [___]% — сәулет басқармасында келісілгеннен кейін
  2. Жоба (П) — [___]% — жиынтық берілгеннен кейін
  3. Сараптаманың оң қорытындысы — [___]%
  4. Жұмыс құжаттамасы — [___]%
Аванс: [___]%, пропорционалды есепке алынады.

Мерзімдері: барлығы [___] күн; кезеңдер бойынша — кесте (2-қосымша).
Сараптаманы сүйемелдеу: Жобалаушының міндеті, ескертулерге жауап беру мерзімі — [___] жұмыс күнінен аспайды.
Авторлық қадағалау: [енгізілген / жеке шарт], құны [___].
Жауапкершілік:
  — кезеңді кешіктіру — күніне [___]% өсімпұл, [___]%-дан аспайды;
  — ҚМЖ қымбаттауына әкелген ЖСҚ қателері — қайта жасау шығындарын өтеу;
  — кәсіби жауапкершілікті сақтандыру — [иә / жоқ].
Жобаға айрықша құқықтар: төлемнен кейін Тапсырыс берушіге өтеді.
Кепілдіктер: ЖСҚ қателерін құрылыстың бүкіл мерзімі ішінде қосымша ақысыз жою.
Бұзу: Тапсырыс беруші іс жүзінде орындалғанын төлеп, бас тартуға құқылы.
```

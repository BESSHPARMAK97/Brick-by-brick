# Объектіні пайдалануға қабылдау актісі: құрылымы

> Танысуға арналған үлгі. Пайдаланар алдында құжатты заңгермен бірге ҚР қолданыстағы заңнамасына бейімдеңіз.

```text
САЛЫНҒАН ОБЪЕКТІНІ ПАЙДАЛАНУҒА ҚАБЫЛДАУ АКТІСІ — ҚҰРЫЛЫМЫ ЖӘНЕ ДАЙЫНДЫҚ
(нысанын уәкілетті орган бекітеді; төменде — құрамы және нені дайындау керек)

1. ОБЪЕКТ ТУРАЛЫ МӘЛІМЕТТЕР
   Атауы, мекенжайы, учаскенің кадастрлық нөмірі, жауапкершілік деңгейі
   Нақты ТЭК: жалпы ауданы, тұрғын ауданы, пәтерлер саны, қабаттылығы
2. ҚАБЫЛДАУҒА ҚАТЫСУШЫЛАР
   Меншік иесі (тапсырыс беруші), бас мердігер, техникалық қадағалау, авторлық қадағалау
3. ДАЙЫНДЫҚТЫ РАСТАЙТЫН ҚҰЖАТТАР ТІЗБЕСІ
   [ ] ЖСҚ сараптамасының оң қорытындысы
   [ ] Бас мердігердің сәйкестік туралы декларациясы
   [ ] Техникалық қадағалаудың сапа туралы қорытындысы
   [ ] Авторлық қадағалаудың жобаға сәйкестігі туралы қорытындысы
   [ ] Барлық бөлімдер бойынша атқарушы құжаттама
   [ ] Жүйелерді сынау және іске қосу-реттеу актілері
   [ ] Бөлу актілері және ТШ-ның орындалғаны туралы анықтамалар
   [ ] Лифтілерге құжаттар (куәландыру)
   [ ] Атқарушы геодезиялық түсірілім
4. ҚОРЫТЫНДЫ
   Объект жобаға сәйкес салынған және пайдалануға дайын
5. Қатысушылардың ҚОЛДАРЫ; күні; актіні белгіленген тәртіппен тіркеу

ҚОЛ ҚОЙЫЛҒАННАН КЕЙІН
[ ] Актіні тіркеу / мемлекеттік сәулет-құрылыс бақылауы органдарын хабардар ету
[ ] Мекенжай беру, техникалық паспорт
[ ] Объектіні «Азаматтарға арналған үкімет» КЕАҚ-та бастапқы тіркеу
```

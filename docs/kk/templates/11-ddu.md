# Үлестік қатысу шарты: негізгі талаптар

> Танысуға арналған үлгі. Пайдаланар алдында құжатты заңгермен бірге ҚР қолданыстағы заңнамасына бейімдеңіз.

```text
ТҰРҒЫН ҮЙ ҚҰРЫЛЫСЫНА ҮЛЕСТІК ҚАТЫСУ ШАРТЫ — НЕГІЗГІ ТАЛАПТАР
(үлестік қатысу туралы заңнамада көзделген үлгілік нысанды қолданыңыз; төменде — нені тексеру керек)

[ ] Тараптар: құрылыс салушы (уәкілетті компания), үлескер — толық деректемелер
[ ] Үлескерлердің ақшасын тартуға ЖАО рұқсатының деректемелері
[ ] Үлестік құрылысты ұйымдастыру тәсілі: [ҚТҮК кепілдігі / уәкілетті компания / қаңқадан кейін]
[ ] Объект: мекенжайы, блок, қабат, пәтер нөмірі, жобалық ауданы, бөлмелер саны, жоспары (қосымша)
[ ] Беру кезіндегі пәтердің күйі: [қара / white box / таза] — тізбесімен
[ ] Бағасы, төлеу тәртібі (бір жолғы / бөліп төлеу / ипотека), есепке алу шоты
[ ] Нақты аудан жобалықтан ауытқыған кезде бағаны қайта есептеу тәртібі
[ ] Құрылысты аяқтау мерзімі және пәтерді беру мерзімі
[ ] Үлескердің құрылыс барысы туралы ақпарат алу құқығы
[ ] Кепілдік мерзімі және наразылық білдіру тәртібі
[ ] Тараптардың жауапкершілігі, бұзу негіздері, ақшаны қайтару тәртібі
[ ] Шартты үлестік құрылыстың бірыңғай ақпараттық жүйесінде тіркеу

ҚОЛ ҚОЙҒАНҒА ДЕЙІН ҮЛЕСКЕР АЛАДЫ:
[ ] ЖАО рұқсатының көшірмесі
[ ] Кепілдік / уәкілетті компания туралы мәліметтер
[ ] Жобалық декларация, пәтер жоспары
```

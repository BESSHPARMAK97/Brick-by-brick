# План: единый портал компании

Перенесено из чата «Главная разработка» (25.10.2026). Работа ещё не начата.

## Задача (слова заказчика)

Сайт проекта должен быть шаблоном: в едином портале компании переходишь на свой проект. Стандарты создаёт не проект, а техотдел, но ему нужно прописать стандарт оформления стандартов — шаблон, чтобы вся система была связана.

## Структура

```
Единый портал компании
├── Портфель проектов: список ЖК → «войти в проект»
├── Реестр стандартов: ведёт техотдел, общий для всех проектов
├── Справочники: регионы, города, классы, этапы, виды работ, конструктивы, номенклатура СМР/ТМЦ
└── Шаблоны документов
        │
        ▼
Сайт проекта: шаблон, одинаковый для каждого ЖК
├── Карточка: заполняют один раз, остальное подтягивается из неё
├── Стандарты: проект их не создаёт, а применяет
└── Дорожная карта, календарь, команда, показатели, партнёры
```

1. **Сайт проекта — шаблон.** Новый ЖК получает ту же структуру, меняются только данные карточки. С портала выбираешь проект и попадаешь в его сайт.
2. **Стандарты ведёт техотдел.** Проект видит только подходящие ему стандарты (отбор по полям карточки), отмечает выполнение по чек-листу и может предложить изменение. Предложение уходит в техотдел, а не правит стандарт.
3. **Стандарт оформления стандартов** — обязательный шаблон для любого стандарта. Поля применимости совпадают с карточкой проекта:
   - паспорт: код `СТ-[направление]-[номер]`, версия, владелец, дата утверждения;
   - жизненный цикл: черновик → согласование → утверждён → изменён → отменён;
   - применимость: регион, город, класс, этап, вид работ, конструктив (те же справочники, что в карточке);
   - содержание: цель, область применения, ссылки на СН РК и СП РК, требования;
   - векторная схема;
   - чек-лист: пункт, кто проверяет, чем подтверждается (акт, фото, журнал);
   - сметная номенклатура: коды СМР и ТМЦ из общего справочника;
   - история изменений.

   Для техотдела — форма-конструктор: без обязательных полей стандарт не сохранить.
4. **Дорожная карта** — 20 этапов из дерева прокачки (`docs/skill-tree/`). Они же становятся общим справочником «Этап» для карточки, стандартов и дорожной карты. Пометки из блокнота (расчёты и калькуляторы, ПК «Start», рендеры и буклеты) добавить к нужным этапам.

## Что сделать в прототипе

- Портал компании: портфель из 2–3 проектов-примеров и вход в проект.
- Сайт проекта по шаблону: у каждого проекта своя карточка и свой набор стандартов.
- Реестр стандартов техотдела: список, статусы, входящие предложения от проектов.
- Конструктор стандарта и страница «Стандарт оформления стандартов».
- Дорожная карта на 20 этапах из дерева прокачки.

# Формулы и правила расчёта

## Время

* Дата — номер дня от 1970‑01‑01 (UTC). Момент `t = d` — начало дня `d`.
* Операция, выполняемая в дни `d…e`, имеет `ES = d`, `EF = e + 1`. Дата окончания в интерфейсе — `EF − 1`.
* Ёмкость дня календаря — в сменах: `0 … shiftsPerDay`; предпраздничное сокращение уменьшает ёмкость
  на `часы сокращения / длительность смены` (по умолчанию выключено, применимость проверить по ТК РК).

## Продолжительность работы

```
трудоёмкость, бригадо-смен  = объём / выработка (ед. на бригадо-смену)
смен                        = трудоёмкость / число бригад на операции
число бригад на операции    = min(crewsPerOperation, фронт работ шаблона, пул бригад)
```

Операция занимает рабочие дни своего календаря, пока накопленная ёмкость не достигнет числа смен; нерабочие дни
и дни, недопустимые по климату, пропускаются (операция приостанавливается). Если выработки или объёма нет —
операция помечается «не рассчитано», её длительность 0, выдаётся ошибка, достоверность — низкая.

Объём: из ВОР (`overrides[key].quantityPerZone`) или по удельному показателю:
`удельный показатель × база (м² этажа / кровли / стен подвала / благоустройства) ÷ число захваток`.

## Связи

| Тип | Условие |
|---|---|
| FS | `ES(посл.) ≥ EF(пред.) ⊕ лаг` |
| SS | `ES(посл.) ≥ ES(пред.) ⊕ лаг` |
| FF | `EF(посл.) ≥ EF(пред.) ⊕ лаг` |
| SF | `EF(посл.) ≥ ES(пред.) ⊕ лаг` |

`⊕` — сдвиг на лаг: в рабочих днях календаря последователя или в календарных днях. Отрицательный лаг — опережение.

## Набор прочности бетона (технологический перерыв)

Длительность не задаётся константой — рассчитывается по суткам (EN 1992‑1‑1:2004, принят в РК как СП РК EN 1992‑1‑1):

```
эквивалентный возраст:  t_T = Σ exp(−(4000 / (273 + T_i) − 13,65)) · 1 сут,  при T_i ≤ 0 °C вклад = 0
относительная прочность: β_cc(t_T) = exp( s · (1 − √(28 / t_T)) )
требуемая доля:          %/100  или  МПа / класс бетона
перерыв, сут = min n ≥ 1, при котором β_cc ≥ требуемой доли (не более 90 сут — иначе ошибка)
```

* `T_i` — ожидаемая среднесуточная температура (норма/прогноз), а в сутки с зимними условиями —
  температура бетона при прогреве/термосе (`winterCuringTempC`, по ППР).
* `s`: 0,20 — CEM 42,5R/52,5; 0,25 — CEM 32,5R/42,5N; 0,38 — CEM 32,5N.
* Требования к прочности:
  * распалубка вертикальных конструкций — 0,2–0,3 МПа (СП 70.13330.2012, табл. 5.11), по умолчанию 0,3;
  * распалубка перекрытий — 70 % при пролёте ≤ 6 м, 80 % при > 6 м (там же), либо значение по ППР;
  * движение людей и установка опалубки вышележащих конструкций — не менее 1,5 МПа (СП 70.13330.2012).
* Ограничения модели: β_cc — доля 28‑суточной прочности при +20 °C, принимается равной доле проектной;
  при очень раннем возрасте модель приближённая (минимум 1 сутки). Для договорных сроков калибровать по лаборатории.

## Зимние условия

Зимние условия бетонирования (СП 70.13330.2012, п. 5.11.1): ожидаемая среднесуточная температура < +5 °C
**и** минимальная суточная < 0 °C. Тогда:

* перед бетонированием выполняется операция «Зимние мероприятия» (длительность из каталога), если
  `winterMeasuresIncludedInRates = false`; иначе её длительность 0 — двойной учёт исключён;
* выдерживание считается при температуре прогрева.

Температура дня по норме — линейная интерполяция между серединами месяцев (Pogoda.ru.net, 1991–2020).

## Климатические ограничения операций

День недопустим для операции, если ожидаемая среднесуточная t < `minAirTemp` операции, или (при наличии прогноза)
порывы ветра > ограничения крана для крановых операций. Внутренние «мокрые» процессы освобождаются от ограничения
при временном отоплении здания, наружные — при тепляках/укрытиях.

Резерв по ветру по статистике не включается в даты: при наличии данных пользователя выдаётся оценка
`Σ по дням крановых операций критического пути (дней с сильным ветром в месяце / дней в месяце)`.

## Резервы и критический путь

* Обратный проход: `LF = min(окончание проекта или директивный срок, ограничения от последователей)`,
  `LS` — размещение назад по календарю с той же потребностью в сменах.
* Общий резерв = число рабочих дней календаря операции в `[ES, LS)` (для перерывов — по основному календарю).
* Свободный резерв — то же до ограничения от ранних сроков последователей.
* Критическая операция — общий резерв ≤ 0 (при директивном сроке раньше расчётного — отрицательный).

Разделяются: календарная продолжительность, рабочие смены, технологические перерывы (операции набора прочности
и календарные лаги), организационные простои (ожидание ресурса — `waitDays`), резерв на риски (отдельный буфер
`projectBufferDays`, не размазывается по операциям). Единый процент потерь не применяется.

## Достоверность

`доля = длительность критических операций с подтверждёнными/проектными/нормативными данными / вся длительность критических операций`.
≥ 80 % — высокая, ≥ 50 % — средняя, иначе низкая; предварительный календарь понижает до «средней»,
нерассчитанная операция — до «низкой».

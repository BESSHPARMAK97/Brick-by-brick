# Таблицы ОРС: разбор и план переноса в портал

Разобраны три файла, октябрь 2026. Исправленные копии файлов хранятся у команды проекта; в репозиторий они не кладутся (внутренние цены и сметы).

## Файлы

| Файл | Что это | Кто заполняет |
|---|---|---|
| Чек-лист B0 | Анкета проекта для сметы на стадии эскиза: блоки (размеры, этажи, квартиры по комнатности, лифты, высоты, фундамент, вид проектирования), паркинг, фасад, кровля, проёмы, благоустройство, внутренние сети | Команда проекта → ОРС |
| Калькулятор ПНР (производственно-накладные расходы) | 193 показателя проекта → объёмы и цены накладных: временные здания и сети, ограждения, охрана, сервис, спецодежда, проектирование, изыскания, экспертиза, лаборатория. Цены — справочник «Ресурсы» по 7 городам | ФМ, ОРС Общестрой, ОРС Сети |

## Нужны данные ОРС

Справочник «Ресурсы», Ташкент: часть цен в сумах, часть похожа на тенге; явные опечатки — валидол 640 000 сум, телевизор 22 млн сум, шкаф для посуды 6,7 млн сум, мышь 268 тыс. сум. По Казахстану большой разброс без видимой причины: МФУ Астана 987 тыс. и Алматы 229 тыс., шкаф для ключей 40 тыс. и 280 тыс. Правильные цены может дать только ОРС.

В смете укрупнённые позиции записаны как «количество = деньги» (чистовая отделка — 162,6 млн «шт» и 87,6 млн «чел.-ч»): при загрузке сметы в портал их трудозатраты не учитываются. Чистовая отделка 250 млн целиком в Блоке 1 — вопрос отложен.

## План переноса в портал

1. **Блоки проекта** — сделано: список блоков, итоги в карточке, документах и презентации.
2. **Справочники** — сделано: класс жилья, город, тип каркаса, вид проектирования, назначение блока; для каждого значения указано, как оно называется в калькуляторе ПНР ([variables.md](variables.md#справочники)). Класс «Комфорт+» в калькуляторе ПНР отсутствует — уточняется с ОРС.
3. **Чек-лист B0** — сделано: страница «Чек-лист B0 для ОРС». Площади, дата старта СМР, назначение, этажность, подземные этажи, вид проектирования, квартиры и лифты подставляются из данных проекта. Дубли внутри самого шаблона убраны: количество насосных станций, тепловых пунктов и ВРУ на листе «Внутренние сети» считается из отметок по блокам. Проверки: квартиры по комнатности и лифты по грузоподъёмности сходятся с итогами блока. Выгрузка в Excel по листам шаблона.
4. **Показатели калькулятора ПНР** — сделано: страница «Показатели ПНР для ОРС», 193 строки в порядке листа «Показатели проекта». 84 показателя вводятся в портале и стали переменными с владельцами ФМ проекта, ОРС Общестрой, ОРС Сети (статусы, история, базовая версия ПК Start). Остальные считаются: даты и срок СМР — из графика; этажность, лифты, остановки (этажи над и под землёй), тип каркаса с делением по 12 этажам, подъезды и контур — по блокам; площади, квартиры, машино-места, площадь участка — из данных проекта; класс и город — по справочникам в названиях калькулятора; краны, мойки колёс, площадь паркинга, благоустройство и брусчатка — из чек-листа B0. Выгрузка в Excel строка в строку: колонку «Значение» вставляют в колонку D калькулятора. Проверено пересчётом исправленного калькулятора в LibreOffice: даты, класс, регион и каркас приняты, ошибок в ценах нет.
5. **Расчёт ПНР** — сделано: на странице «Показатели ПНР» портал открывает файл калькулятора ОРС и считает по его формулам и ценам (движок `window.XLSXEngine`: чтение .xlsx в браузере, функции IF, IFS, AND, OR, SUM, AVERAGE, ROUND, ROUNDUP, VLOOKUP, ISNUMBER, YEAR, MONTH). Показатели подставляются из портала. Цены остаются в файле ОРС: файл хранится только в браузере сотрудника, в данные проекта попадают итоги по разделам и статьям. Проверено: все 3 962 формулы исправленного калькулятора совпадают с пересчётом LibreOffice; итог ПНР на тестовом проекте совпал до тенге (42 250 042 тг). В исходном файле Караганда даёт #ССЫЛКА! так же, как в Excel. Расчёт проектирования и изысканий — в том же файле: листы «Расчет ЭП/ДП/РП/ЛД/ИГИ»; выбор района изысканий и вида проектирования по блокам делается в файле ОРС.
6. **Смета из 1С** — сделано: страница «Смета из 1С» читает выгрузку 1С:УСП (Excel, десятки тысяч строк, уровни группировки) прямо в браузере. Объекты, конструктивы и статьи финмодели: внешние сети и ТП, ИРД/изыскания/проект/экспертиза, технадзор и авторский надзор, резерв, остальное — СМР. Пока смета включена, эти пять статей финмодели считаются из неё (тг/м² общей площади с НДС, надзор и резерв — % СМР) и вручную не вводятся; от них считаются бюджет и презентация ПК Start. Производственные накладные расходы сметы сравниваются с расчётом калькулятора ПНР. Файл сметы не сохраняется, в проекте только итоги. Проверено на смете Avenue 31, 1-1: 8 972 115 775 тг, суммы статей совпали с ручным разбором.

# Brick-by-brick

Дорожная карта строительства жилого комплекса в Казахстане.

- [Дорожная карта строительства ЖК](docs/roadmap-zhk.md): этапы, сроки, бюджет, риски, нормативная база
- [Дерево прокачки](docs/skill-tree/index.html): интерактивная версия. Этап открывается после выполнения чек-листа предыдущих. Можно начать его досрочно, указав причину, тогда этап помечается как «начат с риском». У каждого пункта есть ответственный и срок, просроченные пункты подсвечиваются. Данные из карточки проекта подставляются в документы, документы скачиваются в Word
- [Чек-листы перехода между этапами](docs/checklists.md)
- [Образцы документов](docs/templates/README.md): 29 шаблонов в Markdown и Word, от инвестмеморандума до протокола создания ОСИ

Чек-листы и шаблоны генерируются из данных дерева:

```sh
node scripts/export-skill-tree.js
```

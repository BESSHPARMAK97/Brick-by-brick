# Brick-by-brick

## Калькулятор котлована

`index.html` — одностраничный калькулятор объёма котлована под жилой комплекс:

- откосы по таблице крутизны (СН РК 1.03-05) или с вертикальным креплением;
- формула обелиска, въездная траншея (пандус), недобор грунта;
- вывоз с коэффициентом разрыхления, число рейсов, обратная засыпка пазух;
- поперечный разрез в масштабе и копирование отчёта.

Открыть локально: просто открыть `index.html` в браузере. Для публикации подойдёт GitHub Pages (ветка, корень репозитория).

# Brick-by-brick

Дорожная карта строительства жилого комплекса в Казахстане: на русском и казахском языках.

- [Дорожная карта строительства ЖК](docs/roadmap-zhk.md): этапы, сроки, бюджет, риски, нормативная база
- [Дерево прокачки](docs/skill-tree/index.html): интерактивный инструмент
  - **Дерево этапов**: 20 этапов, этап открывается после чек-листа предыдущих. Досрочный старт с причиной, ответственные и сроки, вложения, нормативная база у каждого этапа, ачивки, мини-карта на телефоне
  - **Регионы**: сейсмоопасный юг, север с суровой зимой, запад с агрессивными грунтовыми водами, восток. Выбор региона добавляет пункты в чек-листы
  - **График**: диаграмма Ганта из связей дерева, критический путь, резервы, прогноз даты ключей
  - **Финмодель**: помесячный денежный поток, НДС 16%, кредит, КПН, IRR, NPV, чувствительность
  - **Бюджет**: план и факт по этапам, план заполняется из финмодели
  - **Сроки документов**: реестр АПЗ, ТУ, лицензий, гарантий с предупреждениями за 60 и 30 дней
  - **Риски**: реестр, карта 5×5 со светофором, 11 типовых рисков
  - **Отчёт**: одна страница для банка или инвестора, скачивается в Word
  - **Проекты**: несколько ЖК в одном инструменте, у каждого свои данные; сводка по портфелю
  - **Журнал**: кто и когда что сделал
  - **Қазақша**: переключатель языка для интерфейса и документов
- [Чек-листы перехода](docs/checklists.md) с нормами и региональными пунктами
- [Образцы документов](docs/templates/README.md): 35 шаблонов в Markdown и Word
- [Қазақша чек-парақтар](docs/kk/checklists.md) и [құжат үлгілері](docs/kk/templates/README.md)

## Скрипты

```sh
node scripts/check-skill-tree.js   # проверка страницы и данных (запускается в CI)
node scripts/export-skill-tree.js  # пересобрать чек-листы и шаблоны из данных страницы
node scripts/build-pages.js        # собрать сайт для GitHub Pages в _site/
```

CI (`.github/workflows/check.yml`) проверяет данные и то, что выгрузки в `docs/` совпадают с данными страницы.

## GitHub Pages

Workflow `.github/workflows/pages.yml` публикует инструмент при каждом пуше в `main`. Чтобы он заработал, один раз включите Pages: **Settings → Pages → Source: GitHub Actions**. На Pages данные хранятся в браузере каждого пользователя; общий прогресс команды, журнал с именами и загрузка файлов работают в версии на claude.ai.

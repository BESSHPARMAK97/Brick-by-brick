# Brick by Brick

Методичка и калькуляторы для расчёта объёмов работ и материалов в строительстве, с опорой на нормы Республики Казахстан.

Статический сайт без сборки: откройте `index.html` в браузере или выложите репозиторий на GitHub Pages.

## Разделы

| Страница | Темы и калькуляторы |
|---|---|
| `earth.html` | Траншеи, планировка методом квадратов, разрыхление грунта |
| `kotlovan.html` | Котлован прямоугольный и произвольного контура: откосы, пандус, недобор, вывоз, засыпка |
| `concrete.html` | Объём бетона и опалубки, заказ миксеров, состав бетона по классу, зимнее бетонирование |
| `rebar.html` | Масса и раскрой арматуры, сетки плит с нахлёстами, хомуты со сгущением, сейсмика |
| `masonry.html` | Кирпич и раствор, газоблок и клей, штукатурка, стяжка, утепление, гидроизоляция |

В каждой теме: формула, пример с подстановкой чисел, калькулятор, а ниже — раскрывающиеся блоки «Подробнее», «Частые ошибки» и «Проверь себя».

## Устройство

- `assets/style.css` — общие стили и цветовые токены (светлая и тёмная темы).
- `assets/common.js` — движок калькуляторов: форма строится из описания полей, пересчёт на лету, ведомость с формулами, копирование отчёта, сохранение введённых значений в `localStorage`.
- `assets/<раздел>.js` — описания калькуляторов раздела (`BB.mount({id, title, inputs, compute})`).

Калькуляторы дают предварительные объёмы и не заменяют проект и смету.

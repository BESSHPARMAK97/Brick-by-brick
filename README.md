# Brick-by-brick — Universal Construction Schedule Engine

Веб-сервис для автоматического построения графика производства работ (ГПР) многоквартирных жилых комплексов.
Пользователь задаёт минимум данных (ЖК, Астана, монолит, 15 этажей, дата старта), а детерминированный
расчётный движок сам формирует перечень работ, технологическую последовательность, длительности, календарь
с праздниками РК, зимние мероприятия и сезонные ограничения, ресурсы, критический путь и резервы —
и объясняет каждую дату.

## Запуск

```bash
npm install
npm run dev        # интерфейс на http://localhost:5173
npm test           # автотесты (движок, 10 обязательных сценариев, хранилище, экспорт)
npm run build      # проверка типов + статическая сборка в dist/
npm run smoke      # быстрый прогон движка в консоли
```

## Что умеет

* **Календарь РК** — праздники и переносы из файлов данных со статусом достоверности (2026 — сверено,
  2027–2028 — предварительно), режимы 5/2, 6/1, 7/0 и индивидуальные, смены, исключения подрядчика,
  отдельные календари по видам работ.
* **Климат Астаны** — нормы 1991–2020 для долгосрочного планирования, загрузка прогноза (Open-Meteo)
  для оперативной корректировки, ограничения конкретных работ; зимнее бетонирование по СП 70.13330.
* **Набор прочности бетона** по EN 1992-1-1 (эквивалентный возраст), без универсальных сроков.
* **Каталог 11 видов работ** — монолит, кладка, фасад, кровля, гидроизоляция, инженерные системы, штукатурка
  и стяжка, плитка, малярные, полы, благоустройство. Все выработки без подтверждения помечены как сценарные.
* **Расчёт** — CPM + ресурсное планирование (бригады по профилям, краны, насосы, поставка бетона, опалубка
  с оборачиваемостью, фронт работ), окна недоступности ресурсов, сроки поставок, резервы, критический путь.
* **«Почему эта дата?»** — для каждой операции: исходная длительность, рабочие/нерабочие дни, связи,
  ресурсы, климат, прочность, резервы, источники и предупреждения.
* **Сценарии, журнал версий, сравнение**; экспорт в **Excel** и **PDF**.
